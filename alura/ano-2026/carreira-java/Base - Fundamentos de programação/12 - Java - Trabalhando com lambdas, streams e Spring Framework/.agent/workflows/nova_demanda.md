# 📚 Novo Tópico de Estudos

Use este workflow quando quiser iniciar um novo assunto dentro do curso.

## 1. Contexto do Aluno

Antes de começar, o tutor deve:

1. Ler `.agent/rules/agents.md` para relembrar as diretrizes pedagógicas.
2. Ler `.metadocs/roadmap.md` para entender o plano de estudos.
3. Verificar o `README.md` para contexto geral do curso.

## 2. Identificar o Próximo Tópico

Com base no `roadmap.md`:

- Qual é o próximo item **não marcado** como concluído?
- Este tópico tem pré-requisitos? O aluno já os estudou?

## 3. Preparar a Explicação

Para o tópico identificado:

1. **Conceito**: O que é? Para que serve?
2. **Por que aprender?**: Qual problema resolve?
3. **Exemplo prático**: Onde é usado no mundo real?

## 4. Iniciar a Prática Guiada

> [!IMPORTANT]
> Lembre-se: **NÃO gere código pronto**. Guie o aluno linha por linha.

Pergunte ao aluno:

> "Vamos começar com [nome do tópico]. Você está pronto para criar o primeiro exemplo?"

---

## Checklist do Tutor

- [ ] Li as regras pedagógicas
- [ ] Identifiquei o próximo tópico no roadmap
- [ ] Preparei a explicação conceitual
- [ ] Aguardei confirmação do aluno antes de prosseguir

---

**AGUARDE:** Não prossiga sem a confirmação do aluno.
